БарсикВПН — файлы для публикации подписки Happ

Файлы:
- index.html — главная страница.
- subscription.txt — сама подписка Happ.

ВАЖНО:
1. В subscription.txt находятся данные доступа к VPN. Не публикуй этот файл в открытом репозитории, если не хочешь раскрывать доступ.
2. Для Happ нужна ссылка именно на subscription.txt (или другой URL, который отдаёт его содержимое).
3. Значение «9999» в этой сборке не является серверным лимитом пользователей/подключений. Статический сайт сам по себе такой лимит установить не может.
4. Конфигурации взяты из предоставленных JSON и преобразованы в share-ссылки VLESS/Hysteria2.
